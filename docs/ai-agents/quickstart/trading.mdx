## Install Base MCP

Add Base MCP to your client's MCP config (Claude Desktop shown — Cursor, Claude Code, and Codex are identical):

```json claude_desktop_config.json
{
  "mcpServers": {
    "base-mcp": {
      "command": "npx",
      "args": ["-y", "@base-org/account-mcp@latest"]
    }
  }
}
```

Restart your client. On first use, Base MCP opens a browser tab to connect a Base Account — no API keys, no seed phrase.

## Check your portfolio

```text Prompt
What's in my Base Account?
```

The agent calls `get_portfolio` and reports balances across networks. Use `search_tokens` if you need to resolve a symbol to a contract address:

```text Prompt
Find the contract address for AERO on Base
```

## Execute a simple swap

For everyday trades, Base MCP's `swap` tool routes through the best available DEX:

```text Prompt
Swap 50 USDC for ETH on Base with 0.5% slippage
```

Base MCP returns a `requestId` and `approvalUrl`. The user signs in their Base Account, and the agent polls `get_request_status` until `confirmed`.

## Execute a Uniswap swap with custom routing

When you need a specific route or protocol, fetch calldata from Uniswap's [Routing API](https://docs.uniswap.org/api/quote/overview) and submit it via `send_calls`:

<Steps>
  <Step title="Get a quote from Uniswap">
    ```bash Terminal
    curl -X POST "https://trade-api.gateway.uniswap.org/v1/quote" \
      -H "Content-Type: application/json" \
      -d '{
        "tokenInChainId": 8453,
        "tokenOutChainId": 8453,
        "tokenIn": "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
        "tokenOut": "NATIVE",
        "amount": "50000000",
        "type": "EXACT_INPUT",
        "swapper": "0xYourAgentWalletAddress"
      }'
    ```

    The response contains `quote.tx.to`, `quote.tx.data`, and `quote.tx.value` — a fully encoded swap transaction.
  </Step>

  <Step title="Submit via send_calls">
    Have your agent build a two-call batch: `approve` USDC for the Universal Router, then the router's `execute`:

    ```text Prompt
    Submit this Uniswap swap via send_calls with an approve + execute batch:
    <paste quote.tx>
    ```

    The agent constructs:

    ```json send_calls payload
    {
      "chainId": 8453,
      "calls": [
        { "to": "<USDC>", "data": "<approveData>", "value": "0x0" },
        { "to": "<UniversalRouter>", "data": "<quote.tx.data>", "value": "<quote.tx.value>" }
      ],
      "atomicRequired": true
    }
    ```
  </Step>

  <Step title="Approve and confirm">
    Base MCP returns an `approvalUrl`. The user signs in their Base Account, and `get_request_status` reports `confirmed` with the tx hash. Both calls land atomically — if the swap reverts, the approval is rolled back.
  </Step>
</Steps>

See the full [Uniswap protocol guide](/ai-agents/skills/protocol-interactions/uniswap) for slippage, deadlines, and error handling.

## Extend to any protocol

`send_calls` accepts arbitrary `to` + `data` + `value` calls. That's the primitive you need to extend your agent to any contract on Base:

| Protocol | Pattern |
|----------|---------|
| **Morpho vaults** | `approve` + `deposit(assets, receiver)` — see the [Morpho guide](/ai-agents/skills/protocol-interactions/morpho) |
| **NFT mint** | call the mint function with the right `value` |
| **Governance vote** | call `castVote(proposalId, support)` on the Governor |
| **Lending** | `approve` + `supply` on Aave, Spark, or Moonwell |

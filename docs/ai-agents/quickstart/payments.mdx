## Install Base MCP

<Steps>
  <Step title="Add Base MCP to your client">
    Edit your client's MCP config (Claude Desktop is shown — Cursor, Claude Code, and Codex use the same package).

    **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
    **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
    **Linux:** `~/.config/Claude/claude_desktop_config.json`

    ```json claude_desktop_config.json
    {
      "mcpServers": {
        "base-mcp": {
          "command": "npx",
          "args": ["-y", "@base-org/account-mcp@latest"]
        }
      }
    }
    ```
  </Step>

  <Step title="Restart your client">
    Restart Claude Desktop (or your MCP client). Base MCP now appears in the available tool list.
  </Step>

  <Step title="Connect a Base Account">
    Ask your agent:

    ```text Prompt
    What's in my Base Account?
    ```

    Base MCP opens a browser tab to connect a Base Account — no API keys, no seed phrase. Once connected, the agent runs `get_portfolio` and reports your balances.
  </Step>
</Steps>

<Tip>
**Claude Code, Codex, and Cursor users** — Base MCP works with any MCP client. Drop the same config into `~/.codex/config.toml` or `~/.cursor/mcp.json`.
</Tip>

## Make your first x402 payment

Ask your agent to discover and call a paid API:

```text Prompt
Find a weather API on the x402 Bazaar and get the forecast for New York
```

Your agent searches the [x402 Bazaar](https://www.x402.org/bazaar), calls the chosen endpoint, gets a `402`, and uses Base MCP's `send` tool to pay. Base MCP returns an `approvalUrl`; the user signs once in their browser and the API response comes back.

For autonomous payments without per-call approval, give the agent a dedicated wallet with a [spend permission](/base-account/improve-ux/spend-permissions).

<Tip>
Prefer a CLI? [`awal`](https://docs.cdp.coinbase.com/agentic-wallet/) wraps the same x402 flow for CDP Agentic Wallet:

```bash Terminal
npx awal@latest x402 pay https://api.example.com/paid-endpoint
```
</Tip>

## Gate your own endpoint with x402

Add x402 payment gating to any Express endpoint:

```bash Terminal
npm install x402-express express
```

```typescript TypeScript
import express from "express";
import { paymentMiddleware } from "x402-express";

const app = express();

app.use(
  paymentMiddleware(
    "0xYourAgentWalletAddress",
    {
      "/api/data": { price: "$0.01", network: "base" },
    }
  )
);

app.get("/api/data", (req, res) => {
  res.json({ data: "premium content" });
});

app.listen(3000);
```

The middleware returns `402` to unpaid callers and the CDP facilitator handles verification and settlement. See [Accepting payments](/ai-agents/transactions/accepting-payments) for `hono`, `next`, and the no-code `monetize-service` skill.

## Why your agent needs a dedicated wallet

An AI agent *could* generate its own wallet by creating a random private key through prompting, but this is unsafe:

- The private key appears in the agent's conversation context, where it can be logged, cached, or leaked through middleware
- Any system with access to the agent's prompt history could extract the key
- If the key is compromised, all funds in the wallet are permanently lost

Dedicated wallet services solve this by managing keys in secure infrastructure separated from your agent's runtime. Your agent requests transactions without ever seeing the private key.

## Choose a wallet

<AccordionGroup>
  <Accordion title="Base MCP — recommended" defaultOpen>
    [Base MCP](/ai-agents/skills/wallets/base-mcp) is the official Model Context Protocol server for the Base Account. It plugs your agent directly into Claude Desktop, Cursor, Claude Code, or Codex with a single config entry — no API keys, no seed phrase. The user connects a Base Account in their browser, and the agent gets `send`, `swap`, `sign`, and `send_calls` for arbitrary EIP-5792 contract interactions.

    **Install** by adding to your client's MCP config:

    ```json claude_desktop_config.json
    {
      "mcpServers": {
        "base-mcp": {
          "command": "npx",
          "args": ["-y", "@base-org/account-mcp@latest"]
        }
      }
    }
    ```

    Restart your client and ask:

    ```text Prompt
    What's in my Base Account?
    ```

    Base MCP opens a browser tab to connect the Base Account, then returns the portfolio.

    For autonomous agents that act without per-transaction approvals, connect a dedicated agent wallet with [spend permissions](/base-account/improve-ux/spend-permissions).

    [Base MCP reference →](/ai-agents/skills/wallets/base-mcp)
  </Accordion>

  <Accordion title="CDP Agentic Wallet">
    Coinbase's standalone wallet for AI agents. Authentication is via email OTP — no API keys required in your agent. Private keys stay in Coinbase's secure infrastructure. Native x402 payment support is built in.

    Install the pre-built wallet skills:

    ```bash Terminal
    npx skills add coinbase/agentic-wallet-skills
    ```

    Then ask your agent to authenticate:

    ```text Prompt
    Sign in to my wallet with your@email.com
    ```

    Skills include: `authenticate-wallet`, `fund`, `send-usdc`, `trade`, `pay-for-service`, `monetize-service`, and more. Operates on Base.

    Choose CDP Agentic Wallet when you want an autonomous agent that runs without a browser in the loop. Choose Base MCP when you want a single MCP-native integration with maximum extensibility (`send_calls`).

    [CDP Agentic Wallet reference →](/ai-agents/skills/wallets/cdp-agentic-wallet)
  </Accordion>

## What your agent can do with a wallet

Once your agent has a wallet, it can:

- **Hold <Tooltip tip="Cryptocurrencies pegged to a stable asset like the US dollar (e.g., USDC). 1 USDC is designed to always equal $1.">stablecoins</Tooltip>**: receive and store USDC or other tokens
- **Send and receive payments**: transfer funds to other wallets, pay for API access, or receive payments for services
- **Sign messages**: cryptographically prove that a message or request came from your agent (used for identity verification)
- **Interact with protocols**: call <Tooltip tip="Programs deployed onchain that automatically execute when conditions are met. They power everything from token swaps to lending.">smart contracts</Tooltip> via `send_calls` to swap tokens, provide liquidity, or use any onchain service
